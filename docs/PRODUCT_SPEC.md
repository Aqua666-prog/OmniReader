# Reader App — концепция и основные функции

## 1. Назначение

Собственная Android-читалка для книг, документов и длинных текстов.

Главный принцип: **offline-first** — локальные файлы, библиотека, прогресс, заметки и настройки должны полноценно работать без аккаунта и без интернета.

Приложение должно сочетать три слоя:

1. **Библиотека** — хранение, сортировка, серии, авторы, коллекции, папки.
2. **Reader** — удобное чтение с гибкой типографикой и навигацией.
3. **Research layer** — цитаты, заметки, закладки, словарь, перевод и поиск.

Все локальные функции считаются базовыми. Искусственных Premium-ограничений не предусматривается.

# 3. Импорт и сканирование файлов

## 3.1. Сканирование

- выбор одной или нескольких папок;
- рекурсивное сканирование;
- автоматическое обнаружение новых файлов;
- повторное сканирование без создания дубликатов;
- извлечение метаданных;
- извлечение обложек;
- определение серии и номера тома.

## 3.2. Режимы хранения

### Читать на месте

Файл остаётся в пользовательской папке.

### Импортировать в библиотеку

Файл копируется в приватное хранилище приложения для защиты от случайного удаления другими приложениями.

## 3.3. Удаление

Разделять действия:

- **Удалить из библиотеки** — убрать запись, оставить файл.
- **Удалить файл** — физически удалить файл с устройства.

# 9. Закладки, выделения, цитаты и заметки

Это разные сущности.

## 9.1. Закладка

Сохраняет позицию в книге.

Можно добавить:

- название;
- цвет;
- комментарий.

## 9.2. Выделение

Подсветка текста цветом без обязательного создания отдельной цитаты.

## 9.3. Цитата

Сохраняет:

- текст;
- книгу;
- автора;
- главу;
- позицию;
- цвет;
- дату;
- комментарий.

## 9.4. Заметка

Пользовательский комментарий:

- к выделению;
- к цитате;
- к закладке;
- к позиции в книге без выделения текста.

Поддержать «заметки на полях».

## 9.5. Цветовые категории

Пользователь может назначать свои значения цветам, например:

- жёлтый — важное;
- зелёный — историческое;
- красный — спорное;
- синий — терминология.

# 22. Базовые UX-принципы

1. Текст важнее интерфейса.
2. Частые действия не должны выбрасывать пользователя из книги.
3. Настройки — через компактную нижнюю панель, а не тяжёлые модальные окна.
4. Любые изменения сохраняются автоматически.
5. Читалка должна работать без аккаунта.
6. Интернет нужен только для внешних сервисов и синхронизации.
7. Все локальные функции — базовые.
8. Ошибки распознавания метаданных можно исправить вручную.
9. Любое удаление файла должно быть однозначно отделено от удаления записи из библиотеки.
10. Пользователь сохраняет полный контроль над файлами и данными.

# 25. Итоговая концепция

Приложение должно быть не просто просмотрщиком EPUB, а полноценной персональной системой чтения:

**локальная библиотека + удобный reader + цитаты + заметки + словарь + TTS + поиск + синхронизация.**

Главная цель — сделать чтение быстрым, спокойным и непрерывным, а работу с важными фрагментами — достаточно мощной для художественной, научной, исторической и религиозной литературы.

# Реализация: Reader 0.2.0

После первого MVP реализован следующий слой спецификации:

- Room schema v2 для цитат/выделений/заметок и персонального словаря;
- цветные выделения с сохранением диапазона символов внутри reader block;
- цитаты;
- заметки к выделенному тексту;
- контекстное меню «Простое / Расширенное»;
- внутренний словарь;
- внешний словарь, переводчик и веб-поиск через настраиваемые URL-шаблоны `{text}`;
- глобальный центр «Цитаты / Заметки / Закладки / Словарь»;
- поиск в исследовательском центре;
- Markdown-экспорт исследовательских данных;
- переход из цитаты, заметки, закладки или словарной карточки к месту в книге;
- базовый фоновый Android TTS foreground service;
- Pause / Resume / Stop из уведомления;
- скорость TTS 0.1×–4×;
- высота голоса 0.5×–2×;
- сохранение прогресса при фоновой озвучке.

Следующий крупный milestone: пользовательские шрифты, richer EPUB renderer, горизонтальная пагинация и расширенный TTS MediaSession.

# Реализация: Reader 0.3.0

В milestone 0.3.0 реализованы следующие пункты спецификации:

- импорт и использование пользовательских `.ttf/.otf`;
- глобальный шрифт и отдельный шрифт для конкретной книги;
- Room-backed профиль чтения на книгу;
- отдельные книжные настройки размера шрифта, интервала, полей, темы, выравнивания и режима;
- горизонтальный постраничный режим для reflowable книг;
- отдельный pure-Kotlin pagination layer (`PageChunker`);
- сохранение EPUB-порядка текста и базовых media-блоков;
- извлечение и рендер raster-иллюстраций EPUB;
- базовое выделение footnote-блоков EPUB;
- PDF как постраничный документ через Android `PdfRenderer`;
- генерация обложки PDF из первой страницы;
- `MediaSession` для фонового TTS и Bluetooth/system transport controls;
- TTS Previous / Next;
- локальный полный backup базы, настроек и внутренних ресурсов;
- безопасный staged restore, применяемый при следующем запуске до открытия Room/DataStore;
- Room schema v3 и миграция `2 -> 3`.

## Ограничения milestone 0.3.0

- горизонтальная пагинация reflowable текста пока эвристическая, а не pixel-perfect;
- EPUB renderer не является полным CSS/XHTML browser engine;
- SVG, сложные таблицы, MathML и интерактивные backlinks сносок ещё не реализованы;
- PDF сейчас raster-only: без текстового слоя, поиска, выделения и TTS;
- backup/restore локальный; облачная синхронизация остаётся отдельным этапом;
- restore требует полного перезапуска приложения.

Следующий milestone: точная пагинация, PDF text layer, richer EPUB navigation/layout, sentence-level TTS highlighting и sync foundation.
