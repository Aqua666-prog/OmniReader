# OmniReader 0.6.0

Личная библиотека и Android-читалка на Kotlin / Jetpack Compose. Обновление 0.6.0 перерабатывает библиотеку и оформление чтения поверх функций исходного проекта 0.5.0.

**Статус:** обновлённые исходники. Android-сборка, инструментальные тесты и проверка на устройстве в этой среде не выполнены. Этот архив не является APK или подтверждённым production-релизом. Подробности — в `BUILD_NOTE.md`.

## Что изменилось

- Бумажная светлая тема и тёмная тема с зелёными акцентами. Выбор: системная, светлая, тёмная.
- Адаптивная сетка книжных обложек и компактный список. Выбранный вид сохраняется.
- Карточка продолжения последней незавершённой книги, реальные счётчики библиотеки.
- Нижняя навигация: чтение, книги, заметки, настройки. Дополнительные разделы доступны в боковом меню.
- Постоянный поиск по названию, авторам, серии, коллекции, имени файла и формату; несколько слов и равнозначность «е»/«ё».
- Пять сохраняемых сортировок: последнее открытие, название, автор, добавление, прогресс.
- Убрано ограничение экрана чтения первыми 20 книгами.
- Обложки декодируются в фоновом потоке с ограничением разрешения и кэшем 16 МиБ. Для книг без обложек показывается типографическое оформление с названием и автором.
- Импорт файлов и папок сопровождается индикатором выполнения; операции внутри библиотеки выполняются последовательно.
- Новая карточка книги с крупной обложкой и кнопкой продолжения.
- Компактная панель читалки, отдельное меню оглавления, поиска и озвучки.
- Предпросмотр типографики и цвета страницы прямо в настройках чтения.
- Яркость окна читалки и запрет гашения экрана. Системная яркость не изменяется; состояние окна восстанавливается при выходе.
- Настройки сгруппированы в раскрывающиеся карточки.
- Файл, открытый из проводника, после импорта передаётся на экран чтения.
- Ошибки открытия отображаются с повторной попыткой.
- Сохранение позиции при уходе с экрана и сворачивании приложения; запись прогресса сериализована.
- Загрузка пользовательских настроек завершается до восстановления позиции. В режиме прокрутки больше не рассчитывается вся постраничная разбивка книги.

## Унаследованные возможности

EPUB/FB2/TXT и другие текстовые форматы, PDF и DjVu, архивы комиксов; оглавление, закладки, цитаты, заметки, выделения, личный словарь, экспорт заметок, системное чтение вслух, таймер сна, импорт шрифтов и резервное копирование.

Поддержка конкретного формата зависит от содержимого файла. DRM не поддерживается. EPUB отображается в собственной вёрстке; полноценное воспроизведение CSS, SVG и MathML отсутствует. Для поиска и озвучки PDF нужен извлекаемый текст и Android 15+, для DjVu — встроенный текстовый слой. OCR, облачная синхронизация и разворот из двух страниц не реализованы. MOBI ограничен возможностями исходного парсера, включая поддерживаемые способы сжатия.

## Получение APK через GitHub Actions

1. Распакуйте архив и перенесите содержимое `OmniReader-main` в корень своего репозитория, включая `.github`.
2. Откройте **Actions → Build OmniReader APK → Run workflow** и выберите ветку с обновлённым кодом.
3. После успешного завершения скачайте **OmniReader-0.6.0-debug-apk** из раздела Artifacts.
4. Распакуйте полученный ZIP и установите `app-debug.apk`.

Workflow последовательно запускает загрузку DjVu backend, JVM-тесты, lint и сборку. Отчёты сохраняются в отдельном артефакте. Успех сборки здесь не заявляется: запуск в репозитории пользователя в этой сессии не выполнялся.

## Локальная сборка

Требуются Java 17, Android SDK 36, build-tools 36.0.0 и Gradle 9.5.0 согласно унаследованной конфигурации проекта:

```bash
gradle testDebugUnitTest lintDebug assembleDebug --stacktrace
```

Gradle wrapper не входил в исходный архив. Имея Gradle, можно создать его скриптом `bash tools/bootstrap-wrapper.sh`. CI использует установленный Gradle напрямую.

## Структура

- `ui/theme` — палитры, типографика, формы.
- `ui/components` — обложки, карточки, продолжение чтения.
- `ui/screens` — библиотека, книга, чтение, настройки, работа с заметками.
- `ui/reader` — пагинация, ресурсы книги, параметры окна чтения.
- `util/LibraryQuery.kt` — фильтрация и сортировка библиотеки.
- `data/settings` — DataStore с настройками оформления и чтения.
- `data/db`, `data/parser`, `tts` — исходная база, парсеры и озвучка.
- `docs/QA_0.6.0.md` — проверка на устройстве перед выпуском.

Application ID `com.sergey.reader` сохранён. Version code — 6, version name — 0.6.0. Схема Room v4 не изменялась. Обновление поверх установленного APK возможно при совпадении подписи.

Историческая документация исходной версии сохранена в `docs/history`; её результаты проверок не относятся к обновлению 0.6.0.
